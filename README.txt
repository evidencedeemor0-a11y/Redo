GPT CHIME — FUNCTIONAL UI DEMO
==============================

This release is a more detailed, interactive fictional banking interface.

FEATURES
--------
- Responsive mobile-first layout
- Modern inline SVG icon system (no emoji icons)
- Home dashboard and available balance
- Hide/show balance control
- Transfer money simulation
- Add money/deposit simulation
- Bill payment simulation
- Recent transaction history
- Spending snapshot
- Cards section with freeze/unfreeze behavior
- Replacement-card demo action
- Settings with notification and compact-view preferences
- Reset demo data
- Browser localStorage persistence
- PWA manifest

FILES
-----
Index.html
style.css
script.js
manifest.json
README.txt

RUN
---
Open Index.html directly in a modern browser.

For PWA/service-worker work or production deployment, serve the folder
from a local web server.

IMPORTANT
---------
This is NOT the official Chime app and does not connect to Chime, a bank,
payment processor, or any financial account. It does not process real money.

Do not add real passwords, card numbers, PINs, OTPs, bank credentials, or
other sensitive financial information to this demo without implementing
appropriate security, authentication, compliance, and backend controls.

The visual design uses original GPT Chime branding and a clean SVG icon
system rather than copying proprietary Chime assets exactly.
